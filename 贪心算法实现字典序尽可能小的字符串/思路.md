# 要构造一个字典序尽可能小的字符串 T

```js
你需要在每一步都选择
# S 的头部或尾部中字典序较小的字符。这个问题可以通过以下步骤来解决：

比较头尾字符：在每一步，比较

S 的头部和尾部字符。

选择较小的字符：如果头部字符的字典序小于或等于尾部字符，则从头部删除该字符并加到
T 的尾部；否则，从尾部执行相同操作。

迭代过程：重复以上过程，直到

S 为空。

这个过程可以用一个循环实现，每次循环都比较

S 的第一个和最后一个字符，然后选择合适的一个加到

T 中。但是，当头尾字符相等时，仅仅比较这两个字符是不够的，因为下一个字符可能会影响整体的字典序。在这种情况下，需要进一步比较后续的字符，直到找到不同的字符来决定操作。

这个问题在计算机编程中可以使用贪心算法来高效解决。
```
